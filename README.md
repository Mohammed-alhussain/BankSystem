# Bank System

A console-based bank management system I made in C++. It starts with a login screen where you enter a username and password, and then takes you to a main menu.

From there you can manage clients (add, delete, update, search, and list them all) and do basic transactions like deposit and withdraw. There's also a section to manage users and control what each user is allowed to do in the system. Client and user data is saved to text files so it stays between sessions.
